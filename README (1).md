# 독서정원 (모바일 웹앱)

매일의 독서 시간을 기록하고, 그 기록이 정원처럼 자라나는 걸 볼 수 있는 모바일용 웹앱입니다.
`index.html` 파일 하나로 동작하며, 별도 서버나 설치 없이 휴대폰 브라우저에서 바로 열어볼 수 있습니다.

---

## 1. 사용 방법

1. `index.html` 파일을 휴대폰(또는 PC)에 저장합니다.
2. 파일을 더블탭(또는 더블클릭)해서 브라우저로 엽니다.
3. 아이폰이라면 Safari에서 열고 **공유 → 홈 화면에 추가**를 하면, 앱처럼 아이콘을 눌러 실행할 수 있습니다.
4. 안드로이드라면 Chrome에서 열고 **⋮ 메뉴 → 홈 화면에 추가**를 하면 동일하게 앱처럼 사용할 수 있습니다.

인터넷 연결은 글꼴(Fraunces, Work Sans)을 불러올 때만 사용되고, 기록 데이터는 모두 **휴대폰(브라우저) 안에만** 저장됩니다 (`localStorage`). 서버로 전송되지 않으며, 브라우저 저장공간을 지우면 기록도 함께 사라집니다.

---

## 2. 화면 구성

상단에 3개의 배너 버튼이 있고, 누르면 해당 페이지로 바로 이동합니다.

### 배너 1 — 오늘의 독서 (`오늘 당신의 독서는 어땠나요?`)
- 처음 사용 시 **목표 독서 시간(분)**을 먼저 설정합니다.
- 목표를 설정한 뒤에는 매일 **오늘 독서 시간(분)**을 입력하고 "기록하기"를 누릅니다.
- 입력한 시간과 목표를 비교해 즉시 피드백 메시지가 나타납니다.
  - `0분` → 씨앗 단계 메시지
  - `0분 초과 ~ 목표 미만` → 새싹 단계 메시지
  - `목표와 동일` → 이파리 단계 메시지
  - `목표 초과` → 나무 단계 메시지
- 같은 날 다시 기록하면 **덮어쓰기**되어, 하루에 두 개의 기록이 겹치는 일은 없습니다.
- 상단의 "변경" 버튼으로 목표 시간을 언제든 다시 설정할 수 있습니다.

### 배너 2 — 독서정원 (`당신의 독서정원`)
- 해당 월의 달력이 나타나며, 각 날짜에 그날 기록한 독서 시간에 따라 아이콘이 표시됩니다.
  - 씨앗: 기록이 `0분`
  - 새싹: `0분 초과 ~ 목표 미만`
  - 이파리: `목표와 동일`
  - 나무: `목표 초과`
  - 아직 기록이 없는 날은 흐린 씨앗 아이콘으로 표시됩니다.
- 상단 좌/우 화살표로 이전 달·다음 달을 자유롭게 넘겨볼 수 있습니다.
- 오늘 날짜는 금색 테두리로 강조됩니다.

### 배너 3 — 독서 평균 (`이번달 독서 평균을 살펴볼까요?`)
- 배너 2와 동일한 월 기준으로(월 이동 가능) 다음 통계를 보여줍니다.
  - 총 독서시간 (해당 월 기록 합계)
  - 평균 독서시간 (총 독서시간 ÷ 기록 일수)
  - 목표 달성률 (목표 이상 기록한 날 ÷ 전체 기록 일수 × 100)
  - 기록 일수 (그 달에 기록이 있는 날의 수)
- 하단에는 오늘(또는 가장 최근 기록일)부터 거슬러 올라가며 **목표를 연속으로 달성한 일수**가 불꽃 아이콘과 함께 표시됩니다.

---

## 3. 데이터 구조 (참고용)

브라우저 `localStorage`에 아래와 같은 형태로 저장됩니다.

```json
{
  "goalMinutes": 30,
  "records": {
    "2026-08-01": 0,
    "2026-08-02": 20,
    "2026-08-03": 30,
    "2026-08-04": 45
  }
}
```

- `goalMinutes`: 사용자가 설정한 목표 독서 시간(분)
- `records`: 날짜(YYYY-MM-DD)를 키로, 그날 독서 시간(분)을 값으로 저장 — 날짜당 값이 하나뿐이라 중복 기록이 생기지 않습니다.

---

## 4. 커스터마이징 팁

- **색상**: `index.html` 상단 `<style>` 안 `:root` 변수(`--forest`, `--sage`, `--gold` 등)를 바꾸면 전체 테마 색이 바뀝니다.
- **아이콘**: `<script>` 안 `ICONS` 객체에 씨앗/새싹/이파리/나무 SVG가 정의되어 있어, 원하는 그림으로 교체할 수 있습니다.
- **주 시작 요일**: 현재 일요일 시작(`일 월 화 수 목 금 토`)이며, 월요일 시작으로 바꾸려면 `DOW` 배열과 요일 계산 로직을 함께 수정해야 합니다.

---

## 5. 알려진 제한사항

- 데이터는 기기(브라우저)별로 로컬 저장되므로, 다른 기기와 자동으로 동기화되지 않습니다.
- 목표 시간을 변경하면 과거 기록의 "단계(씨앗/새싹/이파리/나무)"는 **변경 시점의 새 목표 기준**으로 다시 계산되어 보여집니다 (기록된 분(分) 자체는 그대로 유지).
